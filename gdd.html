1. 게임 개요

핵심 컨셉트

Elementalism은 12x5 격자에서 원소 블록을 배치하여 카드 능력을 활성화하는 혁신적인 덱 빌딩 로그라이크 퍼즐 게임입니다. 플레이어는 전략적 사고와 창의적 문제 해결을 통해 적을 물리치고 강력한 덱을 구축해야 합니다.

타겟 오디언스

  • 덱 빌딩 게임 애호가
  • 퍼즐 게임 매니아
  • 로그라이크 팬
  • 전략 게임 플레이어

플레이 시간

30-60분 (1런)

난이도

중간-어려움

재플레이성

매우 높음

장르

덱빌딩/퍼즐/로그라이크

2. 핵심 메커니즘

12x5 격자 퍼즐 시스템

블록 배치

  • • 테트리스 스타일의 원소 블록
  • • 4가지 원소: 불, 물, 땅, 바람
  • • 블록 회전 및 이동 가능

패턴 매칭

  • • 카드의 모양과 격자 패턴 일치
  • • 매칭 시 카드 능력 발동
  • • 원소별 특수 효과 적용
  • • 콤보 시스템으로 연쇄 반응

덱 빌딩 시스템

카드 획득

전투 승리, 상점 구매, 이벤트 보상을 통해 새로운 카드 획득

카드 강화

같은 카드 합성이나 특수 재료로 카드 업그레이드

덱 관리

불필요한 카드 제거, 최적화된 덱 구성

턴 기반 전투

1

블록 배치 단계

원소 블록을 12x5 격자에 전략적으로 배치

2

카드 사용 단계

손패의 카드를 선택하여 사용

3

패턴 매칭 단계

격자의 패턴과 카드 모양이 일치하면 능력 발동

4

적 행동 단계

적이 공격하거나 특수 능력 사용

3. 원소 시스템

불 (Fire)

공격력과 직접 피해에 특화된 원소

  • • 높은 공격력 딜링
  • • 화상 상태이상 부여
  • • 연쇄 폭발 효과
  • • 적의 방어력 무시

물 (Water)

방어와 회복에 특화된 원소

  • • 체력 회복 및 실드 생성
  • • 적의 공격력 감소
  • • 빙결 상태이상 부여
  • • 지속 효과 제거

땅 (Earth)

방어와 지속 효과에 특화된 원소

  • • 강력한 방어막 생성
  • • 독성 지형 생성
  • • 적의 이동 제한
  • • 자원 생성 효과

바람 (Air)

속도와 유틸리티에 특화된 원소

  • • 추가 액션 획득
  • • 카드 드로우 증가
  • • 적의 행동 지연
  • • 블록 재배치 효과

원소 상성 시스템

강화 조합

  • • 불 + 바람 = 화염 폭풍 (범위 피해 증가)
  • • 물 + 땅 = 진흙 늪 (적 이동 봉쇄)
  • • 땅 + 불 = 용암 폭발 (지속 피해)
  • • 바람 + 물 = 얼음 폭풍 (광역 빙결)

상쇄 효과

  • • 불 vs 물 = 효과 약화
  • • 땅 vs 바람 = 효과 상쇄
  • • 균형 잡힌 사용으로 안정성 확보
  • • 특정 상황에서 역이용 가능

4. 진행 시스템

월드 맵 시스템

전투 노드

적과의 전투를 통해 카드와 유물 획득

유적 노드

골드로 카드, 유물, 포션 구매

이벤트 노드

선택지를 통한 위험과 보상

보스 노드

강력한 보스와의 결전

유물 시스템

게임플레이를 극적으로 변화시키는 강력한 아이템

  • • 원소별 특화 유물 (불의 반지, 물의 목걸이 등)
  • • 퍼즐 보조 유물 (자동 회전, 시간 정지 등)
  • • 전투 강화 유물 (추가 데미지, 방어력 등)
  • • 희귀 전설 유물 (게임 룰 변경)

난이도 상승

진행할수록 더욱 도전적인 상황 제공

  • • 적의 체력과 공격력 증가
  • • 복잡한 패턴의 적 등장
  • • 시간 제한 및 특수 조건 추가
  • • 엘리트 몬스터의 특수 능력

7. 아트 스타일

비주얼 방향성

따뜻하고 신비로운 판타지 세계관을 표현하는 2D 아트 스타일을 채택했습니다. 각 원소는 고유한 색상과 효과로 구분되며, 플레이어가 쉽게 인식할 수 있도록 디자인되었습니다.

8. 오디오 디자인

음악 구성

  • 메인 테마: 웅장하고 신비로운 분위기
  • 전투 음악: 긴장감 넘치는 오케스트라
  • 평화 구간: 잔잔한 앰비언트
  • 보스 테마: 각 보스별 고유 BGM

효과음 시스템

  • 원소별 고유 사운드
  • 카드 사용 효과음
  • 블록 배치 및 매칭 사운드
  • 콤보 및 특수 효과 사운드

10. 밸런싱

게임 밸런스 철학

플레이어의 선택이 의미 있고, 모든 전략이 유효하도록 설계했습니다. 어떤 원소나 카드도 절대적으로 강하지 않으며, 상황에 따른 적절한 선택이 승리의 열쇠입니다.

카드 밸런스

  • • 비용 대비 효율성 균형
  • • 희귀도별 파워 레벨
  • • 시너지 카드 조합

원소 균형

  • • 각 원소별 고유 역할
  • • 상성 관계 밸런스
  • • 단독/조합 사용 균형

난이도 곡선

  • • 점진적 난이도 증가
  • • 학습 구간 제공
  • • 최종 보스 도전
